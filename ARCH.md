# Architecture and lane protocol (working document; not part of the published repository)

## What this repository proves

For `m ≥ 1`, `ψ(m) = Σ φ(pᵏ)` over the prime powers `pᵏ` exactly dividing `m`, with the term for
`pᵏ = 2` replaced by `0` (`ψ(1) = ψ(2) = 0`; OEIS A080737). **Theorem (Vaidyanathaswamy 1928;
Hiller 1985; Kuzmanovich–Pavlichenkov 2002; Bamberg–Cairns–Kilminster 2003, Thm 1).** For `N ≥ 1`
and `m ≥ 1`: `GL(N, ℤ)` has an element of order `m` iff `ψ(m) ≤ N`. Corollaries: the finite orders
of `GL(N, ℤ)` are `{m ≥ 1 : ψ(m) ≤ N}`; the least dimension for order `m` is `ψ(m)` (`1` for `m = 2`);
the same over `ℚ`; parity (`ψ` even); finiteness and `m ≤ 2^(N+1)`; the tables `N ≤ 12`; a block of
size `φ(n)` and order `n` for every `n ≥ 1`. Stretch: the same for `SL(N, ℤ)`, `N ≥ 2`.

`Challenge.lean` holds the two definitions (`psi`, `finiteOrders`) and 37 pinned theorems, each
closed in `Solution.lean` (generated by `scripts/gen_solution.py`) by the `_internal` theorem of
the same name in the modules of `Crystallographic/`. `Crystallographic/Defs.lean` restates the two
definitions character for character (same `import Mathlib`).

## The mathematics, module by module

**Psi.** `psi m = ∑ p ∈ m.primeFactors, if p ^ m.factorization p = 2 then 0 else φ (p ^ m.factorization p)`.
Useful Mathlib: `Nat.primeFactors`, `Nat.support_factorization`, `Nat.factorization_mul` (nonzero
factors), `Nat.factorization_mul_apply_of_coprime`, `Nat.Coprime.disjoint_primeFactors` /
`Nat.primeFactors_mul`, `Nat.Prime.factorization_pow` (`= single p k`), `Nat.Prime.factorization_self`,
`Nat.totient_prime_pow`, `Nat.totient_eq_prod_factorization` (`φ n = n.factorization.prod fun p k => p^(k-1)*(p-1)`),
`Nat.totient_even`, `Nat.totient_mul`, `Nat.recOnPosPrimePosCoprime` (cases `0`, `1`, `p^k` with `k > 0`,
coprime `a * b` with `1 < a, b`), `Nat.prod_primeFactors_pow_factorization`, `Nat.divisors`,
`Nat.mem_divisors`, `IsPrimePow` (`isPrimePow_nat_iff`), `Finset.sum_fiberwise` /
`Finset.sum_comp`, `Finset.sum_le_sum`. The sum-vs-product fact: for a finite family of naturals
each `≥ 2`, the sum is at most the product (induction; the empty product is `1 ≥ 0`). For
`le_two_pow_psi`: every prime power `q ≠ 2` has `q ≤ 2 ^ φ q` (`q = 3`: `3 ≤ 4`; `q ≥ 4`:
`φ q ≥ q / 2` and `2 ^ (q/2) ≥ q`), `2 ≤ 2 ^ 1`; multiply over the factorization with the fully
additive `ψ' = ψ + [2 ∥ m]`, so `m ≤ 2 ^ ψ' m ≤ 2 ^ (ψ m + 1)`. For `psi_le_sum_totient`: pick
`d p ∈ S` for each `p ∈ m.primeFactors`; `m.factorization p ≤ (d p).factorization p`, so the
`p`-term of `ψ m` is at most the `p`-term of `ψ (d p)` (the `2`-exception only lowers the left side;
`φ (p ^ ·)` is monotone); regroup by `d` (`Finset.sum_fiberwise_of_maps_to`) and use `ψ d ≤ φ d`.

**Necessity.** Work with `M : Matrix (Fin N) (Fin N) ℚ := (A : Matrix _ _ ℚ)` for `A : GL (Fin N) ℚ`.
`orderOf (A : Matrix) = orderOf A` (`orderOf_units`). If `orderOf A = 0` then `psi 0 = 0`. Else
`m := orderOf A > 0`, `M ^ m = 1`, so `aeval M (X ^ m - 1) = 0` and `f := minpoly ℚ M ∣ X ^ m - 1`
(`minpoly.dvd`; `M` is integral: `Matrix.isIntegral` / `IsIntegral` from Cayley–Hamilton);
`f ∣ M.charpoly` (`Matrix.minpoly_dvd_charpoly`), `natDegree f ≤ N` (`Polynomial.natDegree_le_of_dvd`,
`Matrix.charpoly_natDegree_eq_dim`, `Matrix.charpoly_monic`). `X ^ m - 1 = ∏ d ∈ m.divisors, cyclotomic d ℚ`
(`Polynomial.prod_cyclotomic_eq_X_pow_sub_one`). `S := m.divisors.filter (fun d => cyclotomic d ℚ ∣ f)`.
Pairwise coprime (`Polynomial.cyclotomic.isCoprime_rat`, `d ≠ d'`), so `∏ d ∈ S, cyclotomic d ℚ ∣ f`
(`Finset.prod_dvd_of_coprime`), hence `∑ d ∈ S, φ d = natDegree (∏ …) ≤ natDegree f ≤ N`
(`Polynomial.natDegree_prod` of monics / `Polynomial.Monic.natDegree_mul`, `Polynomial.natDegree_cyclotomic`).
Cover: for `p ∈ m.primeFactors` with `q := p ^ m.factorization p`, suppose no `d ∈ S` has `q ∣ d`.
Every `d ∣ m` with `q ∣ d` has `cyclotomic d ℚ ∤ f`, hence `IsCoprime (cyclotomic d ℚ) f`
(`Irreducible.coprime_iff_not_dvd`, `Polynomial.cyclotomic.irreducible_rat`); so `f` is coprime to
`∏_{d ∣ m, q ∣ d} Φ_d` (`IsCoprime.prod_left`) and `f ∣ ∏_{d ∣ m, ¬ q ∣ d} Φ_d`
(`IsCoprime.dvd_of_dvd_mul_left`, after splitting the product with `Finset.prod_filter_mul_prod_filter_not`).
The divisors `d ∣ m` with `¬ q ∣ d` are exactly the divisors of `m / p` (`Nat.factorization`
comparison or `Nat.dvd_div_iff_mul_dvd`), so `f ∣ X ^ (m / p) - 1`, `M ^ (m / p) = 1`
(`Polynomial.aeval_eq_zero_of_dvd_aeval_eq_zero`, `minpoly.aeval`), `orderOf A ∣ m / p`
(`orderOf_dvd_iff_pow_eq_one`), impossible as `0 < m / p < m`. Then `psi_le_sum_totient`. For `ℤ`:
`Units.map (RingHom.mapMatrix (Int.castRingHom ℚ)).toMonoidHom`, injective (`Units.map_injective`,
`Matrix.map_injective`, `Int.cast_injective`), and `orderOf_injective`.

**Block.** `g := Polynomial.cyclotomic n ℤ`, monic (`Polynomial.cyclotomic.monic`), `natDegree g = φ n`
(`Polynomial.natDegree_cyclotomic`). `R := AdjoinRoot g`, `pb := AdjoinRoot.powerBasis' hmonic`
(`pb.dim = natDegree g`, `pb.gen = root g`). `Algebra.lmul ℤ R : R →ₐ[ℤ] Module.End ℤ R`
(injective: `Algebra.lmul_injective` or `LinearMap.mulLeft_injective`) and
`LinearMap.toMatrixAlgEquiv pb.basis : Module.End ℤ R ≃ₐ[ℤ] Matrix (Fin pb.dim) (Fin pb.dim) ℤ`
(`Mathlib/LinearAlgebra/Matrix/ToLin.lean`); compose to an injective ring hom `φ : R →+* Matrix …`,
then `Units.map φ.toMonoidHom`. `root g` is a unit: `root ^ n = 1` since `g ∣ X ^ n - 1`
(`Polynomial.cyclotomic.dvd_X_pow_sub_one`, `AdjoinRoot.mk_eq_zero`, `AdjoinRoot.mk_X`), so
`isUnit_ofPowEqOne`. `orderOf (root g) = n`: `root ^ d = 1` iff `g ∣ X ^ d - 1`; for `0 < d < n`
this fails because over `ℚ` (`Polynomial.map_dvd_map` with `Int.castRingHom ℚ`, injective, `g` monic)
`cyclotomic n ℚ` is coprime to every `cyclotomic e ℚ`, `e ∣ d` (`e ≠ n`), hence to
`X ^ d - 1 = ∏_{e ∣ d} Φ_e`, and a coprime divisor of a nonzero polynomial is a unit — contradiction
with `natDegree = φ n ≥ 1`. (`orderOf_eq_iff`, or `orderOf_dvd_iff_pow_eq_one` + `Nat.le_of_dvd`.)
Transport the order: `orderOf (Units.map φ u) = orderOf u` (`orderOf_injective`), `orderOf u = orderOf (root g)`
(`orderOf_units`). Finally reindex `Fin pb.dim` to `Fin (φ n)` with `Matrix.reindexAlgEquiv ℤ ℤ (finCongr h)`
(or state the block over `Fin pb.dim` and `Fin.cast`), through `Units.mapEquiv` /
`MulEquiv`, which preserves `orderOf`. Block sums: `Matrix.fromBlocks A 0 0 B` with
`Matrix.fromBlocks_multiply`, `Matrix.fromBlocks_one`, `Matrix.fromBlocks_inj`; a ring hom
`Matrix (Fin a) (Fin a) ℤ × Matrix (Fin b) (Fin b) ℤ →+* Matrix (Fin a ⊕ Fin b) (Fin a ⊕ Fin b) ℤ`
is easy to define by hand (`map_mul` is `fromBlocks_multiply` + `simp`), injective; or use
`Matrix.blockDiagonal'RingHom` over `Bool`/`Fin 2`. The orders: `(A, 1)` and `(1, B)` commute, their
images multiply, `Commute.orderOf_mul_eq_mul_orderOf_of_coprime`; `orderOf (A, 1) = orderOf A` via
injective homs (`MonoidHom.inl`). Reindex `Fin a ⊕ Fin b ≃ Fin (a + b)` by `finSumFinEquiv`. Padding
is the block sum with `1 : GL (Fin (N - a)) ℤ` (`orderOf_one`, `Nat.Coprime u 1`) and
`a + (N - a) = N`. The sign: `(-1 : GL _ ℤ)` commutes with everything, `orderOf (-1) = 2`
(`orderOf_units`, `orderOf_neg_one`, `ringChar (Matrix (Fin N) (Fin N) ℤ) = 0` for `N ≥ 1`;
`Nontrivial`), `Nat.Coprime 2 u` for odd `u`; `-A = (-1) * A`.

**Sufficiency.** `Nat.recOnPosPrimePosCoprime` with motive
`m ↦ 0 < m → (Odd m ∨ 4 ∣ m) → ∃ A : GL (Fin (psi m)) ℤ, orderOf A = m`: case `0` vacuous; case `1`:
`psi 1 = 0`, `A = 1`, `orderOf 1 = 1`; case `p ^ k` (`k > 0`): `p ^ k ≠ 2` from the hypothesis,
`psi (p ^ k) = φ (p ^ k)` (`psi_prime_pow_internal`), the cyclotomic block; case `a * b` coprime,
`1 < a, b`: the hypothesis passes to both factors (both odd, or `4` divides one and the other is odd;
`Nat.Coprime` with `2`), `psi (a * b) = psi a + psi b` (`psi_mul_internal`), `exists_orderOf_eq_mul`.
Then `exists_orderOf_eq_psi`: if `m` is odd or `4 ∣ m`, done; else `m = 2 * m'`, `m'` odd, `m' ≥ 3`
(`m ≠ 2`), `psi m = psi 2 + psi m' = psi m'` (`psi_two`), `0 < psi m'` (`psi_eq_zero_iff_internal`),
`exists_orderOf_eq_two_mul`. `exists_orderOf_eq_internal`: `m = 2` is `orderOf_neg_one_gl`; otherwise
`exists_orderOf_eq_of_le`.

**Main.** Glue. `isLeast_dimension`: membership from `exists_orderOf_eq_psi` (or `-1` for `m = 2`,
`1` in `GL (Fin 0)` for `m = 1`: `psi 1 = 0`, `orderOf 1 = 1`), lower bound from
`psi_orderOf_le_internal` (and `0 < N` when `m = 2`: `GL (Fin 0) ℤ` is a subsingleton, every
element is `1`, `orderOf 1 = 1 ≠ 2`). Rational version: `Units.map (RingHom.mapMatrix (Int.castRingHom ℚ))`
is injective, so the integer witness has the same order over `ℚ`. Parity: `psi m ≤ N + 1` with
`psi m` even and `N` even gives `psi m ≤ N`. Finiteness: `Set.Finite.subset (Set.finite_Iic _)`.

**Compute / Tables.** `psiC` is desk-defined (see `Compute.lean`). `stripPow_spec` by induction on
`fuel`; `psiAux_eq` by induction on `fuel` generalizing `p m`: the invariant is `m < (p + fuel)²`,
`2 ≤ p`, and `∀ q prime, q ∣ m → p ≤ q`. Key facts: a number `1 < m < p²` with no prime factor
`< p` is prime (`Nat.exists_prime_and_dvd`, `Nat.minFac_sq_le_self`, `Nat.minFac_prime`); if `p ∣ m`
and `m` has no prime factor `< p` then `p` is prime (`Nat.minFac p ∣ m`, so `p ≤ minFac p ≤ p`);
after stripping, `m'` has no prime factor `< p + 1` and `Nat.Coprime (p ^ k) m'`; then
`psi_mul_internal`, `psi_prime_pow_internal`, `psi_zero`, `psi_one`, `Nat.totient_prime_pow`,
`Nat.totient_prime`. Tables: `rw [finiteOrders_eq_internal]`, `Set.ext`, for `→` use
`le_two_pow_psi_internal`, `← psiC_eq_psi`, and a `decide +kernel` of
`∀ m, m < 2 ^ (N + 1) → 0 < m → psiC m ≤ N → m ∈ ({…} : Finset ℕ)`; for `←` each member by
`decide +kernel` on `psiC`. Time `N = 12` (`m < 8192`) first; if the kernel is slow, split the range.
`IsGreatest`: rewrite with the table, `simp`/`decide` on the finite set. Never `native_decide`.

## Rules (every lane)

1. Every statement in a skeleton file is **pinned**: keep its name, hypotheses and conclusion. Add
   any helpers you like in **your own file**; weaken nothing. If a pin is wrong or unprovable as
   stated, prove the nearest correct version under a new name, leave the pin with its `sorry`, and
   say so in your report (the desk re-pins). Never edit another lane's file or `Challenge.lean`;
   if you need a fact from another module, use its pinned statement as a black box, or prove a
   private copy named `aux_…` in your file and report the duplication.
2. Build only through `bash scripts/lane-build.sh Crystallographic.<Module>` from your worktree
   root (two machine-wide slots; a free-memory wait). Never run `lake build` or `lean` directly,
   never more than one build at a time, never `lake build` with several targets. Name helpers
   with your lane's prefix (`psi_`, `nec_`, `blk_`, `suf_`, `cmp_`, `tbl_`, `sl_`) so names never
   clash at the merge. A helper named `pure` or `id` clashes with the prelude.
3. Kernel-only: no `native_decide`, `axiom`, `sorry` outside pins still open, `unsafe`, `partial`,
   `implemented_by`, `mutual`, `opaque`; `decide +kernel` is fine. Mathlib is `v4.35.0-rc2`
   (`if_pos`/`if_neg` → `ite_eq_left`/`ite_eq_right`; `push_neg` → `push Not`;
   `le_or_lt` → `le_or_gt`; section `variable` hypotheses need `include`).
4. Commit on your branch in your worktree as you go (`git add <your file>; git commit`); never
   push; never touch files outside your lane. Scratch files go under your worktree, never `/tmp`.
5. Report (the structured schema): status `DONE` / `PARTIAL` / `BLOCKED`; the pins closed; the pins
   left open with the obstacle; wrong pins with the corrected statement; the line count; whether the
   module builds sorry-free; anything the desk must know (duplicated helpers, API surprises).
6. Time: 2.5 hours of lane time for the Lean lanes (`sl`: 2 hours), then report what is closed.
